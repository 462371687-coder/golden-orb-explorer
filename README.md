# Golden Orb Explorer

【首页 - 3D 交互 Hero】

- 页面中央是一个 3D 旋转物体，不是静态文字

-  Three.js 3D 场景，中央有一个可拖拽旋转的 3D，这个物体是一个抽象的品牌符号（如栖茶的菱形 LOGO）如图

- 支持鼠标拖拽：按住左键拖动，物体跟随鼠标 360° 旋转

- 支持滚轮缩放：放大缩小观看细节

- 支持触摸：移动端手指滑动旋转

- 物体材质：暖金色 #C8915F，金属质感，有环境光反射

- 背景：#F5F0E8（暖米白），极简干净

- 物体下方小字："品牌与视觉设计师 · 拖拽旋转探索"

- 页面加载时物体缓慢自转，吸引注意力
